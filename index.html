@huyanxius/ui
组件预览 GitHub

React 基础组件与主题

适用于 React 19 和 Tailwind CSS 4。颜色、字体、圆角、阴影和动效由主题变量控制。Inkpaw 主题提供浅色与深色。

组件

Button
主要、次要和危险操作
Input
表单输入、文件选择与校验状态
Select
带分组的单选菜单
Dialog
弹窗与键盘焦点管理
Badge
状态与分类标签
Calendar
选择日期或日期范围
Skeleton
加载时的内容占位

接入

pnpm add '@huyanxius/ui@git+https://github.com/huyanxius/ui.git#fc144aa524a58b49e7a0b2c3e272438cb3c9db50'

配置 Tailwind 和主题 Apache-2.0
